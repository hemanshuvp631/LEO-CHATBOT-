## 🎯 HOW TO ADD NEW QUESTIONS

### Step 1: Open script.js in a text editor

### Step 2: Find the chatbotResponses object (near top)

### Step 3: Add your question before the closing brace:

```javascript
newTopic: {
    keywords: ['keyword1', 'keyword2', 'keyword3'],
    responses: [
        "First response option",
        "Second response option",
        "Third response option"
    ]
},
```

### Step 4: Save and refresh browser - Done! ✨

## 🔍 HOW KEYWORD MATCHING WORKS

```
User: "Tell me a joke"
         ↓
System converts to lowercase: "tell me a joke"
         ↓
Searches: Does any keyword match?
         ↓
Found: "joke" in chatbotResponses.joke.keywords
         ↓
Picks random response from that category
         ↓
Displays: "Why do programmers prefer dark mode? 🌙"
```

**Key Points:**
- Keywords are case-insensitive
- Bot uses first matching category
- If no match, fallback response is shown
- Random response picked from category

## 🎨 CUSTOMIZE COLORS

### Edit style.css - Find the :root section:

```css
:root {
    --primary-color: #6366f1;      /* Main brand color */
    --secondary-color: #8b5cf6;    /* Accent */
    --neon-cyan: #06b6d4;          /* Highlight */
    --neon-pink: #ec4899;          /* Alternative accent */
}
```

### Example: Change to Blue Theme

```css
:root {
    --primary-color: #3b82f6;      /* Blue */
    --secondary-color: #1e40af;    /* Dark Blue */
    --neon-cyan: #0ea5e9;          /* Light Blue */
    --neon-pink: #f472b6;          /* Pink */
}
```

**Find color codes:** https://www.colorpicker.com/

## 🐛 TROUBLESHOOTING

**Q: Chatbot doesn't respond?**
A: Make sure keyword in your question matches the keywords in script.js

**Q: Styling looks wrong?**
A: Make sure all 3 files are in the SAME folder

**Q: Can't open index.html?**
A: Right-click → "Open with" → Choose your browser

**Q: Want to remove sidebar?**
A: Remove the <aside> tag from index.html

**Q: How to hide the dark mode?**
A: Check CSS - the dark colors are in :root variables

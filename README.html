⚙️Setup Instructions

Step 1: Download Files

You should have these 3 files:

  • index.html - Main HTML structure
  • style.css - Styling and animations
  • script.js - Chatbot logic

Step 2: Create a Folder

Create a new folder on your computer (e.g., "leo-chatbot")

Step 3: Place Files

Put all 3 files in the same folder. Your folder structure should look like:

leo-chatbot/
├── index.html
├── style.css
└── script.js

Step 4: Open in Browser

Double-click index.html to open the chatbot in your browser!

✨ That's it! The chatbot is ready to use. No installation, no server needed!

❓How to Add Chatbot Questions

Understanding the Response Structure

Each chatbot response has three parts:

{
    keywords: ['keyword1', 'keyword2'],
    responses: [
        "Response 1",
        "Response 2",
        "Response 3"
    ]
}

Step-by-Step: Adding a New Question

1Open script.js in a text editor

2Find the chatbotResponses object (near the top)

3Add your new question before the closing brace }:

weather: {
    keywords: ['weather', 'temperature', 'forecast', 'rain'],
    responses: [
        "I can't check the weather right now, but you can visit weather.com! 🌤️",
        "Check a weather service like weather.com for current conditions! ☀️"
    ]
},

4Save the file

5Refresh your browser - it's ready to use!

💡 Pro Tips:
  • Keywords are case-insensitive (automatically converted to lowercase)
  • Bot picks a random response from the array
  • Add as many keywords as you want for better matching
  • Use emojis in responses for personality! 😊
  • Separate multiple lines with \n

Example: Adding Sports Question

sports: {
    keywords: ['sports', 'football', 'basketball', 'soccer', 'cricket'],
    responses: [
        "I love sports! 🏆 Are you a fan of any particular sport?",
        "Sports are awesome! 🎮 Do you play or watch?",
        "Great question! 🏅 What's your favorite sport?"
    ]
},

🔍How Keyword Matching Works

The Matching Algorithm

Leo uses a simple but effective keyword matching system:

  1. User types: "Hello, how are you?"
  2. System converts to lowercase: "hello, how are you?"
  3. System checks each response category
  4. Finds "hello" matches the "greeting" category
  5. Picks a random response from that category
  6. If no match found, returns fallback response

Example Flow

User Input: "Tell me a joke!"
        ↓
Lowercase: "tell me a joke!"
        ↓
Search: Does it contain "joke"?
        ↓
Found in: chatbotResponses.joke.keywords
        ↓
Random Response: "Why do programmers prefer dark mode? 🌙"

Matching Rules

  • Keywords can appear anywhere in the message
  • Partial matches work (e.g., "hi" matches "this is great")
  • Only one response category is matched per message
  • First matching category wins
  • If no match, fallback response is used

Example Messages and Matches

User Message Keyword Found Response Category
"Hi there!" "hi" greeting
"Tell me a joke please" "joke" joke
"What is JavaScript?" "javascript" javascript
"Goodbye!" "goodbye" goodbye
"Xyz123 random text" None fallback

🎨How to Customize Chatbot Colors

Find the Color Variables

Open style.css and look for the CSS Variables section at the top:

:root {
    --primary-color: #6366f1;        /* Indigo */
    --secondary-color: #8b5cf6;      /* Purple */
    --neon-cyan: #06b6d4;            /* Cyan */
    --neon-pink: #ec4899;            /* Pink */
    /* ... more colors ... */
}

Change Primary Color (Main Brand Color)

Replace #6366f1 with your color code:

--primary-color: #ff6b6b;  /* Change to Red */

📝How to Change Chatbot Name

Change Name to "Alex"

1Open index.html

2Find this line:

<h1>Leo</h1>

3Replace with:

<h1>Alex</h1>

4Save and refresh browser

Optional: Change Avatar Emoji

Find the bot avatar emoji:

<div class="message-avatar bot-avatar">🤖</div>

Change 🤖 to any emoji you like:

<div class="message-avatar bot-avatar">🎨</div>

Change Welcome Message

Open script.js and find:

const welcomeMessages = [
    "Hey there! I'm Leo, your AI assistant. Ask me anything! 🌟",
    // ... more messages
];

Edit to your preference:

const welcomeMessages = [
    "Welcome! I'm Alex, here to help! 💡",
    "Hi! Ask me anything!",
];

🚀Deploy on GitHub Pages (Free Hosting)

Prerequisites

  • GitHub account (free at github.com)
  • Your 3 chatbot files ready

Step-by-Step Deployment

1Create GitHub Repository

  • Go to github.com/new
  • Repository name: leo-chatbot
  • Click "Create repository"

2Upload Files

  • Click "Add files" → "Upload files"
  • Drag and drop your 3 files
  • Click "Commit changes"

3Enable GitHub Pages

  • Go to repository Settings
  • Scroll to "Pages"
  • Source: select "main" branch
  • Click Save

4Get Your URL

  • Wait 1-2 minutes for deployment
  • Your URL will be: https://yourusername.github.io/leo-chatbot
  • Share this link with anyone!
✨ Bonus: Every time you update files in GitHub, your website updates automatically!

Alternative: Use Netlify (Even Easier!)

  1. Go to netlify.com
  2. Click "Add new site" → "Deploy manually"
  3. Drag and drop your 3 files
  4. Get your free URL instantly!
💡 Note: Your chatbot works completely offline - you can share it with anyone!

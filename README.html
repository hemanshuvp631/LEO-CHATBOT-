✅ No special characters in folder name ### **Issue: Bot doesn't respond** **Solution:** - ✅ Keywords must match exactly - ✅ Case doesn't matter (hi = HI = Hi) - ✅ Check script.js syntax - ✅ Refresh browser (Ctrl+F5) ### **Issue: Styling looks wrong** **Solution:** - ✅ style.css in same folder - ✅ Clear browser cache - ✅ Try different browser - ✅ Check CSS file isn't corrupted ### **Issue: Quick buttons don't work** **Solution:** - ✅ All files together - ✅ JavaScript enabled in browser - ✅ No syntax errors in script.js - ✅ Check browser console for errors ### **Issue: Can't edit files** **Solution:** - ✅ Right-click → Open with Notepad/TextEdit - ✅ Use free editor: VS Code, Sublime, Atom -
